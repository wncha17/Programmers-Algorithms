## 📝 [Sorting] K번째수 (Lv. 1)
> **문제 링크:** [https://school.programmers.co.kr/learn/courses/30/lessons/42748]

### 1. 🔍 Key Signal (문제의 단서)
- **키워드:** "i번째부터 j번째까지 자르고", "정렬한 후", "k번째에 있는 수"
- **알고리즘:** 정렬(Sorting) & 슬라이싱(Slicing)
- **판단 근거:**
  1. 배열의 특정 부분집합(Subset)을 추출해야 한다.
  2. 추출된 부분집합 내에서 크기 순서를 따져야 하므로 정렬이 필수적이다.
  3. 데이터 크기가 크지 않아 파이썬의 기본 정렬(O(N logN))로 충분히 해결 가능하다.

### 2. 💡 Strategy (설계)
- **[Solution 1] 리스트 컴프리헨션을 활용한 간결한 풀이**
  - 로직: commands의 각 원소 [i, j, k]를 순회하며, 인덱스 규칙(1-based to 0-based)에 맞춰 자르고 정렬함.
  - 특징: 파이썬다운 코드로 가독성이 높으며, 실무에서 빠른 구현이 필요할 때 유용함.

- **[Solution 2] map과 lambda를 활용한 한 줄 풀이**
  - 로직: 전체 과정을 하나의 익명 함수로 정의하여 매핑함. 
  - 특징: 코드가 극도로 짧아지지만, 가독성 측면에서는 논의가 필요할 수 있음.

### 3. ⚠️ Pitfalls
- **인덱스 오프셋(Index Offset)**: 문제는 '1번째'부터라고 말하지만, 프로그래밍 언어의 리스트는 '0번째'부터 시작한다. i-1과 k-1 처리를 정확히 하는 것이 수능 수학에서 '미만의 범위'와 '이하의 범위'를 구분하는 것만큼 중요하다.
- **원본 보존**: sorted()는 원본을 유지하며 정렬된 새 리스트를 반환하고, .sort()는 원본 리스트 자체를 정렬한다. 상황에 맞게 선택해야 한다.

### 4. 🏟️ Real-world Connection
- **차량 센서 데이터 구간 분석**: 현대자동차의 원격 진단 시스템에서 차량의 특정 주행 구간(예: 100km~200km 지점) 동안 발생한 엔진 회전수(RPM) 데이터 중 중간값이나 특정 순위의 값을 추출하여 엔진의 상태를 진단할 때 사용된다.
- **로그 페이징(Paging) 처리**: 백엔드 API에서 수만 개의 로그 중 사용자가 요청한 특정 페이지의 데이터만 정렬해서 보여주는 페이징 로직의 가장 기초적인 형태이다.
